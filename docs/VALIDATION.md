## M1 fuzz evidence

Local `cargo-fuzz 0.13.2`, `libfuzzer-sys 0.4.13`, and
`rustc 1.101.0-nightly (16d1ffac1 2026-10-26)` compiled both targets successfully
with AddressSanitizer. WAD and map targets each completed 100,000 runs, seed 1,
maximum input 1048576 bytes, RSS limit 1024 MiB, timeout 10 seconds, using only
original synthetic seeds and their generated mutations.

The first WAD campaign completed its inputs but LeakSanitizer failed at process
exit because this managed environment restricts ptrace/thread inspection. Both
campaigns were rerun successfully with `ASAN_OPTIONS=detect_leaks=0`. Address
sanitization remained enabled; **leak detection was not verified**. No parser
crash was observed in the successful campaigns. The environment-exit artifact
and generated corpus entries remain ignored local output. No security settings
were changed. Reproduction commands and corpus provenance are in the test guide.
