## Genuine original-C evidence

[Provenance](../../tests/reference/m3f2_provenance.json) records exact source and
adapter SHA-256s, compiler/flags, ABI assumptions, fixture inputs and output hashes.
The generator compiles **40 extracted genuine bodies**, plus original numeric/RNG
translation units. This inventory includes dependencies that are not entered by
the admitted unbound scenarios; it is not function or branch coverage.

Genuine P_LoadBlockMap executes against the public classic words. Remaining
geometry/seg initialization and the named-field actor/terminal-state ABI are
declared projections, not complete original structs, P_SetupLevel/P_GroupLines or
actor spawning. Original bodies retain collision, XY/Z, spatial linking, thinker,
BSP and sight decisions. Unsupported gameplay callbacks abort if reached.

All **30 synthetic maps** actually execute in **36 scripts / 4,608 tics**. Inputs
include geometry at 512/513 and the new envelope; positive/negative translated
multi-sector scenes; a wide origin-crossing strip; 1,536-unit axis lines and diagonals with components 768 + 768;
24/25-unit steps/dropoffs; negative and high floors; tall sight actors; closed
openings; signed nonzero origins; dense/shared/suffix/dummy-only cells; repeated
children; REJECT; and 1,024 lines at expanded coordinates. Public binary inputs and
the exact setup CSV are committed. The wide airborne scripts move from −1,920 to +1,920
and in reverse using source XY/Z and all sixteen sectors. Grid scripts genuinely
index above 4,096 and relink across cells. A duplicated-child DAG actually executes
16,382 sight work units, rather than merely passing setup.

[The counter](../../tools/reference/summarize_m3f2.py) computes these from actual
tables. Full sight records include kind/index/padding as well as source values;
the five encoded slots are not five independent semantic results. The separate
seg assertion overlaps the complete trace and does not add unique observations.
RNG indexes and actor lastlook are compared; no complete raw-draw transcript is
claimed. Generational identity reuse is a Rust policy, not an original-C pointer feature.

[Rust comparisons](../../crates/doom-sim/tests/m3f2_reference.rs) check raw XYZ and
momentum, constraints/location, dimensions/flags, openings, source movement and
thing/thinker/sector ordering. Complete source sight instrumentation checks node
start/end, leaf/seg order, duplicate decisions, side tests, openings, fractions,
clipped slopes and blockers. Source REJECT returns before geometric observations.
Read-only operations preserve complete canonical state.

The genuine C program was also compiled with `-fno-wrapv`, signed-integer-overflow,
integer-division and float-cast sanitization, with recovery disabled. Every mode
completed without findings and produced identical bytes. This is a scoped arithmetic
audit, not exhaustive UBSan/ISO-C portability coverage. GNU89 integer widths,
arithmetic right shift, GNU negative setup-shift interpretation, little-endian
words and IEEE binary64 are pinned explicitly. New signed overflow is not used as
a compatibility result. Extreme primitive rays are one raw unit inside the domain;
outside-domain rejection is independently tested as Rust policy.

## Independent canonical-state evidence

[The independent encoder](../../tools/reference/m3f2_snapshot_goldens.py) produces
**4,480 DSIM-v19 captures and 70 complete byte fixtures** from original-C physical
and event-order rows, synthetic classic bytes and documented schema predicates.
It never reads Rust output. Vertical diagnostic contact bits use source predicates
and recorded pre-Z C values. [Encoder provenance](../../tests/reference/m3f2_snapshot_provenance.json)
hashes every input/output. All per-tic digests and complete fixtures match; full
fixtures diagnose the first different named field. The two-actor script retains
direct C comparisons and is deliberately excluded from independent full-state encoding.

The asserted `map_extent` example checks source candidate order and the complete
sixteen-sector route, independent first/final bytes, repeated instances, a real
high-cell script with independent bytes, and the full-expansion sight fixture.
Debug/release output agrees; independent final digest **`2c13f52d732a12c4`**.
DSIM-v19 composes the untyped layout under an explicit tag; it is neither an
original savegame nor a vanilla demo. DSIM-v1–v18 data and meaning remain frozen.

## Rust-specific safety evidence

Twelve focused [policy tests](../../crates/doom-sim/tests/m3f2_policies.rs) cover
old/new constructor separation, raw-unit coordinate/momentum margins, separate
line-norm/node/height/origin domains, full-height and negative-floor actors,
actual 8,192-cell indexing, first encounters and same-cell head relinking,
reference/raw-word/memory/collision-work ceilings, full expanded DAG rejection,
malformed references and specials, slot exhaustion/zero capacity, pending removal,
generation reuse and all-actor failure atomicity. Unsupported player, typed/combat,
AI/hearing and map-spawn paths reject. A late actor outside its next-tic margin
cannot partially move earlier actors or consume pending events/RNG. Pause,
presentation reads, smaller successful budgets and independent instances remain
deterministic. These are safe Rust admission contracts, not claims that unsafe
original C inputs reject the same way.

## Fuzzing and sanitizers

All **18 fuzz targets** build with AddressSanitizer. The new bounded campaign
completed **4,096 actual executions in 65.90 seconds with no findings**, with 54
deterministic synthetic seeds, libFuzzer seed 1, maximum 35 bytes/eight operations,
at most eight tics per instance and four actor slots. Inputs cover expanded
coordinates/origins, malformed/shared lists, repeated children and work exhaustion,
capacity, stale references, controls, pause, RNG wrap and two-instance equality.
Rejected operations compare the entire canonical state.

Per-input timeout was 20 seconds; RSS limit was 2,048 MiB. `ASAN_OPTIONS=detect_leaks=0` disabled leak
detection: **there is no LeakSanitizer coverage**. Wall time includes the launcher.
This finite campaign is not exhaustive source coverage. Corpus/artifacts are
ignored development outputs; the committed seed tool reproduces the initial inputs.

## Host memory and timing observations

[Raw three-sample measurements](m3f2-measurements.json) identify Linux x86_64 and
rustc 1.99.1 release builds. The [host tool](../../tools/measure_map_extent.py) uses a
native wait4 launcher to measure Rust process high-water RSS without Python's
pre-exec resident pages. Each separate process measures 100 parses, 100 complete
simulation preparations excluding parsing, 1,000 collision queries, 1,000 sight queries,
and 100 snapshot-inclusive tics. Preparation includes geometry/sight validation,
BLOCKMAP/topology work and canonical-cache construction; these are not separate
subsystem timers. The cloud host is nonexclusive; timing differences are observations,
not a performance threshold or controlled causal regression claim.

Medians; timing columns are total microseconds for those operation counts. Prepared
storage is actual requested owned capacities for lines/lists, leaf sectors and
runtime sector heights. It excludes parsed Map, actors, snapshots, caches and
allocator overhead. RSS includes those process effects, so it is a different metric.

The shared 8,192-cell case has 262,144 prepared references; sparse has 8,378.
Dense 1,024-line queries visit 1,024,000 collision candidates across 1,000 queries;
the DAG queries execute 16,382,000 sight work units and 16,384,000 diagnostic visits.
These workloads differ substantially. Only the small identical fixture/profile
comparison has the same input and operation volume, and host contention/noise
still prevents a universal speed claim. Measurements do not combine every raw
padding/list-start/line/cell worst case; the architecture states independent
complexity/resource bounds instead of treating observed samples as worst-case proof.

## Regression, documentation and preservation

Mandatory local validation passed: workspace build and both format checks,
warnings-denied Clippy/rustdoc, **316 workspace tests, 316 Rust 1.85.0 tests**
(two private asset opt-ins ignored), **292 release tests**, all nineteen
original-C/independent-encoder pairs and all nineteen asserted debug/release
examples. The scoped C arithmetic audit, parser quickstart and documentation
checks also passed. Exact platform readiness belongs to the PR/Actions and is a
separate required gate.

Documentation retains a single authoritative home per category. README keeps its
prominent machine-maintained/human-directed notice. ROADMAP separates merged M3f1,
M3f2 owner review and broader planned readiness. The standing AGENTS/CONTRIBUTING
rules remain applicable without a milestone log. Original source/history/attribution,
GPL-2.0-only, historical schemas/helpers/fixtures and archive digests are preserved: all 165 original upstream files, all 5,285 pre-existing
reference/tool/support paths and twenty archive digests verified unchanged.
Dependency locks, ancestry and Git integrity checks also passed. No private resources,
credentials, commercial IWADs or unrelated repositories were accessed.

Complete player/monster/map admission, dynamic sectors, map specials, rendering,
extended formats and vanilla demos remain unsupported. Source 64-cell/128-intercept
semantics are unchanged. Future map-readiness work needs separate owner direction
and another independently justified source/ownership/arithmetic investigation.
