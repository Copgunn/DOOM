## Implemented scope and boundaries

GameInstance owns one unchanged Simulation and one opaque incarnation key. Checked
reference export/import reuse ExecutionContext and its invariant ContextActor
brands. Moves preserve identity; wrapping cloned/extracted state and successful
restart create a new incarnation. Failed setup preserves state and identity.
Retained references keep only their small key, not actor/world storage. Existing
generation/definition/state/action guards remain authoritative; import is not a
lease or gameplay permission. The raw Simulation API remains explicitly local.

No actor/Simulation storage field, second store/scheduler, per-tic provenance
lookup, global ID counter, RNG draw, capacity, gameplay profile or DSIM change is
introduced. Identity is private Arc allocation equality, not content equality or
an address serialized as a number. There is no numeric/byte InstanceId constructor,
savegame restoration, networking or authentication. Deliberately attaching a known
local key to erased raw data is explicit local interpretation, not origin recovery.

The original savegame/level-setup source was read for pointer reconstruction and
lifetime assumptions. This is source investigation, not new compiled behavior
coverage or savegame compatibility. Original C has no equivalent Rust incarnation
contract; the provenance guarantees below are Rust safety/API policy.

### Separate provenance workload

This workload has no historical before API. Setup/admission is excluded; both
paths time 100,000 validated imports and 100,000 checked exports (including Arc
drop), then 100 same-input snapshot-inclusive updates/target observations. The
scoped path retains its already scoped actor; the qualified path deliberately
reimports on each update. Ordinary tic logic never automatically imports refs.
Both paths end with the same digest. Validation work differs and timings are noisy.

| Path | Import100000 samples us | Export100000 samples us | Update100 samples ms | Median RSS KiB |
| --- | --- | --- | --- | --- |
| scoped | 1464 / 1467 / 1516 | 1355 / 1351 / 1349 | 14.539 / 14.629 / 14.778 | 2600 |
| qualified | 1501 / 1507 / 2430 | 1361 / 1396 / 2706 | 14.478 / 14.429 / 14.379 | 2616 |

Scoped-path import/export medians were 1467/1351us per 100000, or 14.67/13.51ns per
operation. Qualified-path medians were 1507/1396us (15.07/13.96ns). Its third sample
was 2430/2706us and is retained. Update medians were 14.629/14.429ms per 100 calls;
the lower qualified median does not prove that extra validation improves speed.

Code inspection shows one small key allocation at construction/successful restart,
borrowed-key import and allocation-free Arc sharing at export. No allocation
counter or actor-store RSS isolation was instrumented. Internal actor handles and
all ordinary gameplay paths remain local. These limited measurements do not prove
zero overhead or universal performance equivalence.

## Documentation, preservation and remaining work

The README, architecture, identity, compatibility/trust, unchanged-format note,
testing, roadmap and evidence indexes were reviewed together. The scoped context
and raw local APIs retain their distinct contracts; keys do not become persistence
or authentication. The selected next recommendation is bounded original player
body mo/attacker and damage/death ownership admission, not another automatic
identity abstraction. No such gameplay is implemented here.

Native Intel CI retains every check and receives the same headroom as Linux after
an observed post-merge job cancellation near the former 15-minute budget. This
feature-branch change does not alter the reviewed master baseline, job names,
Intel runner selection, expected outputs or validation requirements. Exact attempts,
conclusions and checkout commits belong to GitHub.

Persistent/remote instance resolution, savegame restore, networking/authentication,
real-player execution, new species/Spectre, infighting, respawn/raise, dynamic
sectors, broader projectiles, rendering/Vulkan and PK3/ZScript remain unsupported.
Public raw readmission still requires caller discipline. Production panic/flag
maintenance and reference-storage growth remain separately scoped roadmap items.

Final review passed: 73 Markdown files, 864 relative links, 95 anchors and 20 exact
archives. All 165 upstream blobs and 6019 historical paths are byte-identical;
licenses/attribution, both lockfiles, ignored asset tests, old source/fixtures/tools
and history are preserved. The measured runtime source fingerprints match final
files, and Git integrity checks passed. The repository remains public with
GPL-2.0-only workspace licensing. No private/UZDoom/GZDoom implementation, commercial
asset, incompatible dependency or framework was accessed/imported.
