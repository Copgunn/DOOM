# M3g8 engineering evidence

## Source-first checkpoint

The [investigation](../M3G8_REFERENCE_INVESTIGATION.md) defines the bounded source
contract. Before Rust runtime changes, the new compiled-C observer generated
27 scenarios / 5,664 scripted tics / 913 selected captures. Normal, strict
arithmetic and ASan/UBSan executions matched byte-for-byte. Address checks used
`ASAN_OPTIONS=detect_leaks=0`; no leak-detection claim is made.

The independently specified DSIM24 projection contains 12 full-byte fixtures,
5,691 event frames and 78,174 ordered event payload fields. Source observations
include 132 fist attacks, 19 pistol bullets, 98 shotgun pellets and 98 chaingun
bullets. These are new scenarios through inherited source functions, not newly
invented function/branch coverage. Exact inventories and hashes live in the
[source](../../tests/reference/m3g8_provenance.json) and
[encoding](../../tests/reference/m3g8_snapshot_provenance.json) manifests.

Runtime implementation, complete validation and performance results are pending
at this source-only checkpoint. This record will be completed before owner review.
