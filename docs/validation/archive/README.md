These documents retain the full pre-M3d3j explanations and evidence. They are
historical observations, including limitations and pending states at that time.
Use the [validation guide](../../VALIDATION.md) for current reproduction and evidence.

Each `.txt` is a byte-identical copy from verified master
`97052fb6e2491453466b64918b15f319d88958a1`; each Markdown copy changes only relative
link destinations and adds a historical banner. The [manifest](manifest.json)
records original byte sizes, SHA-256 digests, navigation-copy digests, and every
original heading, mapping each section to its complete archive document.
